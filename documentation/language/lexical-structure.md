# 词法结构

## 关键字

### 声明关键字

| 关键字 | 说明 |
|:---|:---|
| `micro` | 轻量级函数声明 |
| `structure` | 不可变值类型声明 |
| `class` | 类类型声明 |
| `component` | ECS 组件声明 |
| `system` | ECS 系统声明 |
| `enums` | 枚举声明 |
| `flags` | 标志位声明 |
| `union` | 联合类型声明 |
| `import` | 导入声明 |
| `export` | 导出声明 |
| `namespace` | 命名空间声明 |

### 语句关键字

| 关键字 | 说明 |
|:---|:---|
| `let` | 不可变变量绑定 |
| `let mut` | 可变变量绑定 |
| `if` / `else` | 条件分支 |
| `while` | 条件循环 |
| `loop` | 遍历循环 |
| `match` | 模式匹配 |
| `case` | 匹配分支 |
| `when` | 守卫分支 |
| `catch` | 效应捕获 |
| `resume` | 恢复执行 |
| `return` | 返回 |
| `end` | 模板块闭合（仅模板模式） |

### `let` 与 `let mut`

- `let x = expr`：不可变绑定，派生计算，赋值后不可修改
- `let mut x = expr`：可变绑定，可变状态，允许后续赋值

### `micro` 轻量函数

`micro` 是 Valkyrie 中声明函数的唯一关键字，替代 `fn`、`function`、`func`、`def`：

```valkyrie
micro add(a: i32, b: i32) -> i32 {
    return a + b
}
```

## 标识符

- 以字母或下划线开头
- 后续可包含字母、数字、下划线
- 大小写敏感
- 不可与关键字冲突

## 字面量

### 布尔字面量

```
true  false
```

### 空值字面量

```
null
```

### 整数字面量

```
42          # 十进制
0xFF        # 十六进制
0o77        # 八进制
0b1010      # 二进制
1_000_000   # 下划线分隔
```

### 浮点字面量

```
3.14
1.0e10
1.0e-10
```

### 数字后缀

| 后缀 | 类型 | 示例 |
|:---|:---|:---|
| `i8` | 8 位有符号整数 | `127i8` |
| `i16` | 16 位有符号整数 | `32767i16` |
| `i32` | 32 位有符号整数 | `42i32` |
| `i64` | 64 位有符号整数 | `999999i64` |
| `u8` | 8 位无符号整数 | `255u8` |
| `u16` | 16 位无符号整数 | `65535u16` |
| `u32` | 32 位无符号整数 | `42u32` |
| `u64` | 64 位无符号整数 | `999999u64` |
| `f32` | 32 位浮点数 | `3.14f32` |
| `f64` | 64 位浮点数 | `3.14f64` |

### 字符串字面量

```valkyrie
"hello"
"你好，世界"
"line 1\nline 2"
"嵌套 {variable}"
```

| 分隔符 | 说明 |
|:---|:---|

## 注释

```valkyrie
# 行注释

<#
  块注释
  支持嵌套 <# 内层注释 #>
#>
```

- 行注释以 `#` 开头，到行尾结束
- 块注释以 `<#` 开头，`#>` 结尾，支持嵌套

## 元代码块

```valkyrie
<% if condition %>
    ...
<% end %>

<% expr %>
```

元代码块用于编译期代码生成和模板渲染，详见 [Template 扩展](template-extension.md)。
